# Feedback and contributions

This repository contains public examples and product documentation. Application source-code contributions are not accepted here.

For a prompt example, broken link or documentation correction, open an issue or a small pull request. Include the page or example name, what you expected and what you observed. Describe your browser and the relevant generation settings when they help reproduce a problem.

Do not post passwords, API keys, session cookies, verification links, payment details, private prompts, account identifiers or customer uploads. Crop or redact personal information from screenshots. Do not attach someone else's images without permission.

For account-specific or security-sensitive matters, use the contact or support options available on https://seedanceai.dev rather than a public issue. Do not publish exploit details or production data here.

Contributions must be original or clearly licensed for inclusion. Keep sample provenance and limitations accurate, and do not replace actual outputs with mockups presented as generated results.
